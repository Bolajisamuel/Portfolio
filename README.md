# Portfolio Website assignment for Microsoft Class

A responsive portfolio website for **Bolaji Samuel**, a surveying and geoinformatics professional (BSO Geospatial & Engineering Consults), showcasing GIS projects, skills, and a contact form.

**Live site:** https://bolajisamuel.github.io/portfolio/

## Features

- Semantic HTML structure (header, nav, main, sections, articles, figures, footer)
- Responsive layout for desktop, tablet, and mobile using CSS Grid and media queries
- Mobile navigation menu with a toggle button
- Contact form with client-side validation and error messages
- Accessibility: alt text on images, skip link, ARIA labels, keyboard focus outlines, and high-contrast colours
- SEO basics: descriptive title, meta description, and a clear heading hierarchy

## Sections

1. **Home:** introduction and call to action
2. **About Me:** professional background
3. **Projects:** arable land suitability DSS, gold mining web GIS, automated map generation
4. **Skills:** QGIS, ArcGIS Pro, AutoCAD Civil 3D, HTML/CSS/JavaScript, Git
5. **Contact:** validated contact form

## Built With

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- JavaScript (DOM manipulation, event handling, form validation)

## Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/Bolajisamuel/portfolio.git
   ```
2. Open the folder:
   ```
   cd portfolio
   ```
3. Open `index.html` in your browser.

## Deployment

Hosted with GitHub Pages from the `main` branch (root folder).
